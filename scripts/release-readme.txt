妙手在线自动化客户端 - Windows x64

1. 将整个 miaoshou-client-win-x64 文件夹解压到本机磁盘，不要只复制 start.cmd。
2. 双击 start.cmd。默认浏览器会打开 http://127.0.0.1:3001/。
3. 首次在“业务连接”区输入公网入口的 Basic 用户名和密码，点击“连接”；后续启动会恢复本机保存的凭证。
4. 在“妙手尺码表”实例中启动可见浏览器观察登录，在客户端页面保存账号密码并输入图片验证码；客户端按实际登录账号连接对应业务后端。
5. 如需使用 1688，在“通用自动化”实例中启动无头浏览器，并在页面扫码或完成短信验证。

保持启动命令窗口打开；需要停止客户端时在窗口按 Ctrl+C。关闭网页不会停止客户端。
包内已包含 Node 和 Chromium；用户电脑不需要 Node、npm、WSL2 或项目源文件。
Basic 凭证加密保存在当前 Windows 用户目录，重启后恢复；妙手登录使用浏览器持久 profile，妙手账号密码加密保存在本机。更换网关地址时需要重新输入 Basic 凭证。

如需核对包完整性，压缩包旁的 .sha256 文件记录了 ZIP 的 SHA-256；包内 SHA256SUMS.txt 记录逐文件摘要。
